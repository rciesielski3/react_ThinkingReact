# Thinking in React

[![CI](https://github.com/rciesielski3/react_ThinkingReact/actions/workflows/ci-node20.yml/badge.svg)](https://github.com/rciesielski3/react_ThinkingReact/actions/workflows/ci-node20.yml)

A small React + Vite exercise based on the official "Thinking in React" tutorial: a filterable product table built
from a static component hierarchy, then wired up with state.

## Run

```bash
npm ci
npm run dev      # local dev server
npm run build    # production build
```

Requires Node >= 20.19. See [CHANGELOG.md](CHANGELOG.md) for dependency and CI history.
